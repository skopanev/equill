# Security

## Data handling

Equill stores user-supplied records. Repository examples, tests, bug reports, and
benchmarks must use synthetic data. Do not attach a real store or receipt to a public
issue.

The default runtime contract is local-only, no telemetry, and no network access.
Diagnostics must not print record payloads or evidence content.

## Reporting a vulnerability

Use GitHub's private security advisory flow for this repository. Do not include real
records, credentials, or private infrastructure details in the report.
